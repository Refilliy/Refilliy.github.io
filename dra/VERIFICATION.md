# 검증 범위

2026년 11월 9일 기준. 현재 구성은 양피지 초대장과 입학 안내서, 28명 인물 데이터 및 제공된 완성 이미지, 심볼 9종입니다.

## 정적 확인

- HTML의 상대 링크·앵커·로컬 자산 참조, 중복 ID, `aria-controls` 대상을 확인했습니다.
- JavaScript 구문, CSS 5개 파일의 괄호 구조, 28명의 고유 ID와 데이터 연결을 확인했습니다. 독립 소스 검토에서 선택자 불일치는 발견되지 않았습니다.
- 인물 WebP 28개의 정확한 `1536×640` 치수, 고유 `portrait` 경로와 파일 존재를 확인했습니다. 심볼 WebP 9개는 `1080×1080`이며 투명 채널을 유지합니다.
- WebP 39개의 변환 전후 해상도와 디코딩을 확인했습니다. 인물·성채·이전 콘셉트 이미지는 품질 90, 알파 품질 100이며 심볼 9종은 무손실 압축입니다. 심볼의 모든 알파 값과 투명하지 않은 픽셀의 RGB 값이 원본과 일치합니다. 인코딩 형식이 달라져 배포 파일의 SHA-256은 제공 PNG와 다릅니다. `원본` 폴더의 파일을 선택하지 않았습니다. 비올레타·로제니·에레시안은 셒 버전, 엘레드라는 성체 버전을 사용합니다.
- 이미지 총량은 51.93MiB에서 9.61MiB로 약 81.49% 감소했습니다. HTML·CSS·JavaScript에서 이전 PNG 경로가 남아 있지 않으며, 사이트 폴더에는 WebP 39개가 있습니다.
- 에스미의 공개 신분과 비공개 설정 분리, 제공된 두 채팅 주소, Pages 워크플로와 `.nojekyll`을 확인했습니다.
- 3,603개 면으로 구성한 시설 모형을 SVG로 내보내 PNG로 렌더링해 건물·기숙사 색·시설 배치를 시각 점검했습니다. 이 렌더는 웹페이지 스크린샷이 아닙니다.
- Node의 DOM·Canvas 대체 객체로 7개 시설 선택과 안내 연동, 핀 상태, 회전·확대 범위·초기화, 중복 없는 키보드 처리, 요청할 때만 실행되는 렌더링을 점검했습니다. 900×615, 320×368, 258×340 지도 영역에서 기본 핀의 표시 경계를 확인했습니다.

기본 인물 표시 수는 6명이며, 나머지는 검색·필터·전체 보기로 탐색합니다. 카드 이미지는 12:5 비율이고, 760px 이하에서 한 열로 배치됩니다. 초대장은 네이티브 `details`·`summary`로 열고 접습니다. 세계관·기숙사·학교 소개와 작품 장르는 기본 펼침 상태이며, 인물의 세부 프로필과 스포일러 기록은 기본 접힘 상태입니다.

## 미완료 검증과 배포

내장 브라우저와 로컬 서버 연결이 시간 초과되었고, 브라우저의 로컬 파일 접근도 정책상 허용되지 않았습니다. **실제 브라우저 화면·모바일 렌더링·클릭 동작은 검증하지 못했습니다.** 정적 소스 점검은 화면 검증을 대신하지 않습니다. 외부 채팅 서비스 내부 동작도 확인하지 않았습니다.

GitHub 저장소가 지정되지 않아 실제 공개 배포는 하지 않았습니다. 배포 후 휴대전화에서 초대장 개봉·입장, 메뉴, 탭, 검색·필터·프로필, 시설 선택, 두 채팅 링크를 확인해 주세요. Google Fonts가 차단되면 필기체와 인쇄체 모두 대체 글꼴로 표시될 수 있습니다.
