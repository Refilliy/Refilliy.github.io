# 드라고니움 아카데미아 — 입학 안내서

## 디자인 방향

한 권의 판타지 입학 안내서를 펼치는 경험입니다. 따뜻한 양피지, 세피아 잉크, 숲빛 강조색, 얇은 장식 테두리를 사용합니다. 초대장과 본문을 같은 종이 질감으로 연결하고, 세계관과 학교 안내는 바로 읽을 수 있도록 펼쳐 둡니다.

핵심 주제는 ‘혈통과 지위가 아닌, 관계와 행동으로 자신을 증명한다’입니다. 서명과 짧은 여백 문구에는 영문 Allura와 한글 Nanum Pen Script를 사용하고, 제목·본문·메뉴는 명조와 고딕을 유지합니다.

## 탐색 흐름

| 화면 | 핵심 행동 |
| --- | --- |
| 입장 초대장 | 밀랍 봉인을 열고 학장 아스테리아의 초대를 받아들이기 |
| 안내서 표지·세계관 | 짧은 안내를 읽고 제국·드래곤·상점가·연표 탐색 |
| 세 기숙사 | 가치관·표어·파트너 관계 비교 |
| 함께할 사람들 | 기본 6명에서 시작해 28명 검색·필터·프로필 열람 |
| 학교생활 | 입체 모형 회전·확대, 7개 시설 안내 |
| 이야기 시작 | 세이프·언세이프 채팅 선택 |

세계관의 세부 설명, 기숙사 소개, 학교 소개, 작품 장르는 기본적으로 펼쳐 둡니다. 인물의 세부 프로필과 스포일러 기록은 기본으로 접어 두고 방문자가 원할 때 펼칠 수 있습니다. 입장 초대장은 밀랍 봉인을 누르면 열리는 흐름을 유지합니다.

## 인물 이미지와 모바일

28명 모두 사용자가 제공한 **1536×640px(12:5)** 완성 이미지를 고화질 WebP로 표시합니다. 이미지에 포함된 이름과 테두리가 잘리지 않도록 카드와 상세 창에 같은 비율을 유지합니다. 투명 심볼은 무손실 WebP를 사용합니다. 중복된 세 인물은 셒 버전, 엘레드라는 성체 버전을 사용합니다. 이전 SVG 초상 자리와 `house-leaders.webp`는 보관되어 있으나 현재 페이지에 표시하지 않습니다.

760px 이하에서 인물 카드는 한 열, 본문은 세로 흐름으로 배치합니다. 안내서 본문은 모바일 14px를 기준으로 하며, 필기체는 짧은 문구에 충분한 크기와 행간으로 사용합니다. 초대장과 프로필의 높이를 고정하지 않습니다.

네이티브 초대장 개봉, 키보드 탭 이동, 포커스 표시, 모달 닫기·복귀, 검색 결과 알림, 모션 축소 설정을 제공합니다. 핵심 정보는 이미지에만 넣지 않고 HTML 텍스트로 전달합니다.

## 원안과 구현 범위

시설 안내도는 중정형 본관, 적·청·녹색 지붕의 기숙사, 비행훈련장, 치료동, 온실, 사육농장, 용의 숲을 건축 모형처럼 표현합니다. 실제 3D 좌표를 회전·투영하는 경량 Canvas 렌더러를 사용합니다. 지도를 가로 전체 폭으로 보여 주고 시설 번호·조작 도구·아래 시설 목록을 분리했습니다. 모바일에서는 수평 드래그로 회전하고 수직 스크롤로 페이지를 이동하며, 자동 회전은 없습니다.

28명의 원안 데이터와 인물 관계를 보존합니다. 레브린의 교수·황실 이중 소속, 에스미의 비공개 신분 구분을 유지합니다. 미공개 드래곤 위계나 능력을 새로 확정하지 않습니다. 문장은 사용자가 제공한 심볼 9종을 사용하며, 성채와 시설 배치는 시각적 콘셉트입니다.

본문은 독립된 `assets/guide.css`, 입장 페이지는 `style.css`·`invitation.css`·`handwriting.css`를 사용합니다. 상대 경로와 정적 파일 구성으로 GitHub Pages 배포에 대응합니다.
