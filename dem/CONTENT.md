# 마왕님 힘내세요

## 실행
`index.html`을 브라우저에서 열면 바로 실행됩니다. 설치나 빌드가 필요 없습니다. 웹 서버에는 `dist` 폴더의 내용을 업로드하세요.

## 구성
- `index.html`: 사용자 독백 원문, 작품 소개, 세계관과 원작 결말
- `app.js`: 인물 10명과 8대 종족의 설정, 탭·아코디언·전환 동작
- `style.css`: 데스크톱·모바일 스타일, 동작 줄이기 접근성 설정
- `assets/royal-frame.png`: 참조 대화에서 확보한 원본 장식 프레임

## 콘텐츠
독백은 사용자가 제공한 텍스트를 변경하지 않았습니다. 세계관·종족·인물 설명은 추가로 제공된 설정을 바탕으로 읽기 쉽게 정리했습니다. 짧은 소개 문구와 화면 연출은 웹사이트용 표현이며 새로운 사건이나 능력을 설정하지 않습니다. 사용자가 제공한 캐릭터 배너 9장을 로컬 파일로 포함했습니다. A 루시펠라, B 라임, C 아라크네, D 벨제비아, E 티타니아, F 펜리르, G 오크나, H 뱀피, I 비나입니다. 원본 비율과 이미지 속 이름·심볼을 그대로 보존합니다. 현재 마왕만 별도 제공 이미지가 없어 타이포그래피를 사용합니다. 배경은 분위기를 위한 추상적 CSS 풍경이며 공식 지도가 아닙니다.

Google Fonts를 이용하며 네트워크가 없으면 기기 기본 글꼴로 표시됩니다. 핵심 동작에는 외부 서비스가 필요하지 않습니다. 원작 결말은 버튼을 눌러 펼치는 방식입니다.
